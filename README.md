# Anton Fros — сайт-портфолио

Одностраничный сайт-визитка в одном файле `index.html`. Внутри всё: вёрстка, стили, скрипты и данные кейсов. Картинки и видео не лежат в папке, они грузятся напрямую с Behance, Dprofile и Kinescope.

## Как открыть и посмотреть

- Просто открой `index.html` в браузере (Chrome, двойной клик). Нужен интернет: шрифт и картинки подгружаются из сети.
- Если что-то не грузится при открытии с диска, запусти любой локальный сервер в этой папке, например `npx serve .` или `python -m http.server`, и открой `http://localhost:...`.

## Как выложить в интернет

- **Сайт уже выложен на GitHub Pages:** https://frosti71fros-pixel.github.io/portfolio/ (репозиторий `frosti71fros-pixel/portfolio`, ветка `main`, корень). Обновить: открыть репозиторий → Add file → Upload files → перетащить новый `index.html` → Commit changes; через ~1 минуту сайт обновится. Фото `20250819-MMM06257 1.png` и `portfolio 2026_антон fros.txt` в репозиторий не выкладывались.
- Быстрее всего Netlify Drop: зайти на app.netlify.com/drop и перетащить эту папку. Получится публичная ссылка. Чтобы сайт жил постоянно и можно было поменять адрес, нужна бесплатная регистрация.
- Подойдут также GitHub Pages или Vercel.
- Приватные ссылки Claude Artifacts не подходят: там заблокированы внешние картинки и видео, сайт будет пустым.

## Как продолжить работу с другого компьютера

1. Перенеси эту папку целиком (облако, флешка, GitHub).
2. Открой Claude Code (десктоп-приложение, вкладка Code) и выбери эту папку как папку проекта.
3. Первым сообщением напиши: «прочитай README.md и продолжим работу над сайтом». В этом файле вся история и решения.

## Дизайн-система

- Шрифт: **TikTok Sans** (Google Fonts, с кириллицей, переменная ширина). Узкое начертание запрещено. Широкое (font-stretch 140%) используется только для мелких акцентов вроде «[ 026 ]». Антикву не использовать.
- Цвета (CSS-переменные): фон `#050505`, текст `#e9e9e4`, второстепенный `#7b7b76`, акцент — пыльный бежевый `#c9b79c`, светлая «бумага» `#d5d4cf` + чернила `#0c0c0b`. Светлые экраны получают класс `.light`, который переопределяет переменные.
- Кнопки и плашки без скруглений, квадратные.
- Стрелки — тонкие шевроны без горизонтальной черты (SVG `CHEV_L` / `CHEV_R` в скрипте).
- Каждый экран начинается с шапки `.sh`: чёрный тег «[ 0N ] Название» плюс три метки.
- Курсор: тонкие линии по горизонтали и вертикали через весь экран и координаты `[x, y]`. На тач-устройствах выключен.

## Анимации

- **Слайдер:** барабан рисуется одним WebGL-шейдером на канвасе `#drum` (луч пересекается с цилиндром, все обложки лежат в одной текстуре-атласе). При перелистывании барабан проворачивается на одну грань, а картинки рассыпаются в крупные пиксели и собираются обратно, по экрану вспыхивают глитч-квадраты, рамка выделения подсвечивается бежевым. Название и размеры появляются через перебор символов. Автопрокрутка 6 секунд. Мышь слегка поворачивает барабан (параллакс). Настройки геометрии — функция `geom()`: `S` число граней, `G.f` фокус (больше = площе, изометричнее), `G.pitch` наклон взгляда сверху (отрицательный), `G.band` ширина пиксельного края. Эффекты — шейдер `FS` (функция `panel`, задняя стенка рисуется вторым пересечением луча с кольцом, прозрачность 0.26). Локальный сервер для проверки — `tools/serve.ps1` (устойчив к обрывам запросов). Картинки грузятся с CORS (Behance и Dprofile это разрешают); если WebGL недоступен, в рамке показывается просто обложка.
- Рефы первого экрана (ноябрь 2026): https://ru.pinterest.com/pin/949415165212300099/ (объект на сетке с подписями), https://ru.pinterest.com/pin/1113515076610436491/ (3D-карусель карточек), https://ru.pinterest.com/pin/635781672428108026/ (рамки выделения, размеры, круги).
- **Плитки кейсов:** при наведении карточка инвертируется в светлую, картинка проявляется тем же пиксельным эффектом.
- **Всё ниже первого экрана привязано к скроллу** (движок `SCROLL` в скрипте). Значения плавно догоняют позицию прокрутки, поэтому при прокрутке вверх анимации играют в обратную сторону.
  - Обо мне: слова выезжают снизу из-под маски строки.
  - Клиенты: ряды едут в разные стороны, ряд по центру ярче.
  - Работы: плитки поднимаются при появлении.
  - Награды: счётчики досчитывают, названия выезжают, строки при наведении заливаются.
  - Контакты: «Let's talk» выезжает, квадрат со стрелкой поворачивается.

## Данные

- **26 уникальных кейсов** собраны с Behance (behance.net/anton_fros, 17 шт.) и Dprofile (dprofile.ru/antonfros, 18 шт.). 9 совпадений склеены в один кейс со ссылками на обе площадки. Список в скрипте: массив `CASES`.
- Для кейса, который есть на Behance, контент берётся с Behance (объект `BEH`), иначе с Dprofile (объект `DPF`).
- В `BEH` строка с `~` — картинка, `https://…` — видео, объект `{r:[[путь, ширина], …]}` — ряд картинок сеткой.
- В `DPF` строка — картинка (если в конце `|600`, картинка встаёт в ряд по 4), `{v}` — видео, `{t}` — текстовый блок.
- Tevredens (брендинг, DO Creative) и Tevredens Typeface оставлены разными кейсами: у них разный контент.
- Кейс «БКВЧ 2025» не удалось переснять с сеткой (Dprofile отдал пустую страницу), там картинки идут по одной.
- **Если добавишь новый кейс** на Behance или Dprofile, его нужно вручную добавить в `CASES` и данные. Скрипт для съёма раскладки — `tools/extract-layout.js`.

## Мобильная версия

- На ≤820 px: номер слайда не налезает на лид-текст (кольцо ниже), «Все кейсы» в одну строку (12.5vw), без подписи «Смотреть все кейсы»; в наградах медали под названием, колонка «СЗФО/—» скрыта. Заголовки с пиксельным глитчем не переносятся посреди слова.

- До 820 px верхнее меню сворачивается в кнопку «Меню» (квадратная, с двумя линиями, которые при открытии становятся крестиком). По нажатию открывается панель на весь экран под шапкой: крупные ссылки с номерами экранов [ 02 ]–[ 06 ]. Панель закрывается по клику на ссылку, по Esc и при расширении окна. Пока панель открыта, страница не прокручивается.
- Шапка на узких экранах имеет фиксированную высоту 44 px, под неё подогнаны отступ якорей и липкая строка фильтров.
- До 520 px боковые рельсы слайдера сужаются до 42 px, названия клиентов крупнее (46 px).
- Проверено на ширине 375 px (телефон) и 768 px (планшет), десктоп не изменился.
